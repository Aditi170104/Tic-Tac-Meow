# Tic-Tac-Meow

**Tic-Tac-Meow** is a cat-themed Tic-Tac-Toe game built with HTML, CSS, and JavaScript. Players take turns placing kitten icons (Leo and Coco) to win by aligning three in a row. The project demonstrates DOM manipulation, event handling, and responsive design.

## Features

- Interactive gameplay using JavaScript
- Winner and draw detection
- Responsive layout for mobile and desktop
- Reset functionality to replay the game
- Hover effects and smooth animations

## Technologies Used

- **HTML5**: Structure of the game
- **CSS3**: Styling, responsiveness, animations
- **JavaScript**: Game logic, event handling, DOM manipulation

## How to Play

1. Click on an empty tile to place your kitten.
2. Alternate turns between Leo and Coco.
3. First player to align three icons wins.
4. If all tiles are filled without a winner, it's a draw.
5. Click "Reset Game" to start again.
